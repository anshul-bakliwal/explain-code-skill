# ⚡ Explain-Code: GitHub Copilot Architecture & Data Modeling Skill

An advanced GitHub Copilot slash command (`/explain-code`) that generates multi-tier architecture documentation, nested Mermaid & IcePanel diagrams, OpenSpec-ready domain data models, and deep OpenAPI attribute dependency breakdowns.

---

## 🚀 Quick Install (1 Command)

Open your project's terminal in VS Code and run:

```bash
mkdir -p .github/prompts && curl -fsSL https://raw.githubusercontent.com/anshul-bakliwal/explain-code-skill/main/.github/prompts/explain-code.prompt.md -o .github/prompts/explain-code.prompt.md
